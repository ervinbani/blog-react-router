# Blog React Routing

This application is a sample blog built with **React**, **Vite**, and **TypeScript**.  
It demonstrates **dynamic routing**, **protected routes**, and **authentication management** using the **React Context API**.

The project was developed as part of the **Per Scholas training program** to practice modern React Router concepts.

---

## Main Features

- Client-side routing with React Router
- Dynamic routes using URL parameters (`/blog/:slug`)
- Protected admin page with authentication guard
- Authentication state management using React Context API
- Mock blog posts and products (in-memory data)
- Clean and modular project structure

> **Note:** Blog posts are mock data and are read-only, as required by the lab specification.

---

## Folder Structure

- `src/pages/` — Application pages (Home, Blog, Login, Admin, Products, etc.)
- `src/context/` — Authentication context and logic
- `src/lib/` — Mock data and utility files
- `public/` — Static assets
